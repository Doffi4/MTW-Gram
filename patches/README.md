# Патчи поверх tdesktop

База — коммиты в `BASE`. Наложить на чистый клон `refs/tdesktop` (из корня репо):

```
git -C refs/tdesktop apply --binary ../../patches/tdesktop.patch
git -C refs/tdesktop/Telegram/lib_ui apply --binary ../../../../patches/lib_ui.patch
```

Собрать: `tools\build-win.bat`.

Локальные проверки для предыдущего этапа — `python -m unittest discover -s tools -p "test_*.py"`. Они анализируют исходники. Сравнение отрисовки, проверка камеры и серверного поиска требуют запущенного клиента.

Регрессионная проверка границы прочтения: `python tools/test_compose_visibility.py`. Она проверяет условия из исходников без запуска аккаунта и отправки read receipts. Скрытая капсулой область исключена из прочтений, реакций, просмотров и метрик чтения; рисование и подгрузка используют полную область.

Проверка перед v0.2.0-beta: Debug с исправлением границы прочтения собран 2026-11-06; визуальная проверка обычного чата, ответа/редактирования, записи и меню вложений ещё требуется. Автоматический доступ Computer Use к Telegram не разрешён.

Цвета генерирует `tools/mac_palette.py` из `ColorPalette.swift` Telegram-macOS; после изменения сопоставления — перезапустить его и пересоздать патчи:

```
python -I tools/mac_palette.py <Telegram-macOS>/packages/ColorPalette/Sources/ColorPalette/ColorPalette.swift refs/tdesktop
git -C refs/tdesktop diff --binary -- . ':!Telegram/lib_ui' > patches/tdesktop.patch
git -C refs/tdesktop/Telegram/lib_ui diff --binary > patches/lib_ui.patch
```
