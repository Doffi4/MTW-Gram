## 1. Исходники → таблицы (главное, точнее любых записей)
Из `refs/Telegram-macOS` вытащи числа и положи ссылку «файл:строка» к каждому:
- `recon/tokens.md`: все цвета по ролям для light/dark/night/tinted (палитры из `PresentationTheme`/`TelegramPresentationTheme`/`ColorPalette`, значения hex+alpha), радиусы, отступы, размеры иконок, высоты строк (список чатов, контактов, поиска, настроек), размеры аватарок, толщины разделителей, тени, blur/vibrancy материалы, размеры и стили шрифтов.
- `recon/animations.md`: КАЖДАЯ анимация — элемент, триггер, длительность, curve/spring (mass/stiffness/damping), delay, что именно анимируется (alpha/position/scale/frame), ссылка на код. Искать: `duration`, `timingFunction`, `CASpringAnimation`, `CABasicAnimation`, `animateAlpha`, `animateScale`, `transition`, `ContainedViewLayoutTransition`, `Animator`, `spring`, `easeInOut`. Отдельно: открытие/закрытие чата, пуш/поп навигации, отправка и появление сообщения, пузырь-хвост, реакции, ответ свайпом, контекстное меню, поповеры, тултипы, переключение папок, выбор сообщений, скролл-кнопка, индикатор печати, голосовые, медиа-вьювер (жест закрытия), звонки, смена темы, лист шаринга, поиск, hover-состояния, лоадеры, pull-to-… и любые bounce.
- `recon/layout.md`: размеры и минимумы окна, ширина сайдбара (min/max/дефолт, drag-resize), поведение при сужении (collapse в 3 стадии?), titlebar/traffic lights/toolbar, ширина колонки чата, поле ввода (авто-рост, макс. высота), пузыри (max width, внутренние отступы, радиусы по позиции в группе, хвост), группировка сообщений по времени/автору, даты-разделители, правила превью ссылок/медиа/стикеров/эмодзи.
- `recon/behavior.md`: горячие клавиши (все, из меню и кода), контекстные меню (пункты, порядок, иконки), drag&drop, scroll physics (инерция, rubber band, прокрутка к непрочитанному), выделение текста, курсоры, звуки (когда играют), поведение drag окна, трей/док-бейдж, уведомления (вид, действия), Touch Bar/Handoff игнорируй.
- `recon/INDEX.md`: оглавление всего собранного + список «чего не удалось получить и почему».

## 2. Реальный клиент → скриншоты (`recon/screens/`)
Снимай в родном Retina-разрешении, без масштабирования. Для каждой темы: Light и Dark (и «ночную»/tinted, если есть), два акцента по умолчанию и один другой. Именуй `NN-экран_состояние_тема.png`.
Экраны: логин (все шаги), пустое состояние, список чатов (все типы строк: обычный, закреплённый, непрочитанный, mute, упоминание, черновик, печатает, секретный, канал, бот, папки), поиск (пустой, результаты, нет результатов), чат (личный, группа, канал, форум-топики, бот), все типы сообщений (текст, длинный, ответ, пересылка, фото, альбом, видео, кружок, голосовое, файл, стикер, анимированный, эмодзи, premium-эмодзи, GIF, опрос, локация, контакт, ссылка с превью, инлайн-кнопки, реакции, сервисные сообщения, сообщение удалено/редактировано), выделение сообщений, поле ввода (все состояния: пусто, текст, ответ, редактирование, запись голоса, вложения-меню, эмодзи-панель, стикеры, GIF), контекстные меню (на сообщении, чате, аватарке), профиль (юзер, группа, канал; все вкладки: медиа, файлы, ссылки, голосовые, участники), настройки (каждая страница и подстраница), папки, сторис, звонки (входящий, исходящий, в звонке, видео), медиа-вьювер, шеринг, диалоги (подтверждение, ошибка), тосты, уведомление, меню приложения, меню трея/дока, окно при трёх ширинах (широкое, среднее, минимум).
Используй свой аккаунт или тестовые данные; личные имена/номера замажь или используй тестовый чат (Saved Messages + публичные каналы), чтобы в репозиторий не попали чужие данные.
Для hover/pressed/focus снимай отдельно, если не получается скриншотом — запись.

## 3. Реальный клиент → записи анимаций (`recon/animations/`)
Запись экрана 60 fps (QuickTime/`screencapture -v` или ffmpeg avfoundation), по одному ролику на анимацию, коротко (2–5 с), имя = как в `animations.md`. Для каждого ролика сразу нарезай кадры: `ffmpeg -i x.mov -vf fps=60 frames/x_%03d.png` в `recon/animations/frames/<name>/` (если объём большой — оставь каждый кадр только первых 1.5 с и пакуй zip). По кадрам сверяй длительность и кривую из кода: в `animations.md` добавь колонку «замерено по видео» (мс, число кадров, ощущение кривой). Если код и видео расходятся — приоритет у видео, пометь расхождение.
Обязательные ролики: все пункты из раздела animations.md выше, плюс скролл списка с инерцией, resize сайдбара, свёрнутый/развёрнутый режим, анимация смены темы, набор текста с авто-ростом поля, появление клавиатуры-панелей эмодзи/стикеров.
