## Что снять вручную (или дать разрешение и перезапустить меня)

**Вариант А (рекомендую, 1 заход на мак):** Системные настройки → Конфиденциальность и безопасность → **Запись экрана и системного аудио** → включить **Claude** (и при желании «Терминал»). Затем **Универсальный доступ** → включить Claude. После этого написать мне «продолжи recon: скриншоты и записи» — я сам пройду §3 и §2 по этому списку.

**Вариант Б (руками, ~1 час):**
1. Скриншоты: `⌘⇧4`, затем Пробел и клик по окну Telegram (с тенью снимать не нужно — зажать ⌥ при клике). Порядок и имена — по §3 выше, формат `NN-экран_состояние_тема.png`, складывать в `recon/screens/`.
2. Записи 60 fps: QuickTime → Новая запись экрана → выделить окно; 2–5 с на ролик; имена как ID в `animations.md` (`A3-push.mov`, `B1-send-text.mov`, …). Минимум, нужный для проверки кривой: **A3 push**, **A4 pop**, **B1 отправка**, **E1 контекстное меню**, **G1 модалка**, **M1 вьювер**.
3. Нарезка кадров (ffmpeg уже есть в Python):
   ```
   FF=$(python3 -c "import imageio_ffmpeg as f;print(f.get_ffmpeg_exe())")
   for f in recon/animations/*.mov; do n=$(basename "$f" .mov); mkdir -p recon/animations/frames/$n; "$FF" -i "$f" -t 1.5 -vf fps=60 recon/animations/frames/$n/${n}_%03d.png; done
   ```

Важно: экран этой машины 1x (не Retina) — для пиксельных замеров это удобно (1 px = 1 pt).
