## Что снять вручную

1. **Записи анимаций (главное, что осталось).** QuickTime → Файл → Новая запись экрана → «Записать весь экран» → по 2–5 с на сценарий: **A3 push** (открыть профиль из шапки), **A4 pop** (назад), **B1 отправка текста**, **E1 контекстное меню**, **G1 модалка** (например, «Создать папку»), **H1 переключение папок**, **C2 реакция**, **D1 свайп-ответ**, **N1 смена темы**. Сохранить в `recon/animations/<ID>-<имя>.mov`. Кадры:
   ```
   FF=$(python3 -c "import imageio_ffmpeg as f;print(f.get_ffmpeg_exe())")
   for f in recon/animations/*.mov; do n=$(basename "$f" .mov); mkdir -p recon/animations/frames/$n; "$FF" -i "$f" -t 1.5 -vf fps=60 recon/animations/frames/$n/${n}_%03d.png; done
   ```
   Альтернатива: перезапустить приложение Claude (право «Запись экрана» начинает действовать для shell только после перезапуска) и сказать «запиши анимации» — тогда я сам запишу ffmpeg'ом.
2. На тестовом аккаунте: логин, бот, секретный чат, все типы сообщений, звонок. Карта всех экранов и потоков — `replica/recon.md`, инвентарь 441 контроллера — `replica/screens-inventory.md`.
3. Вьювер аватарки открылся без падения (3-й заход) — падение, видимо, только у вьювера медиа в сообщениях.
