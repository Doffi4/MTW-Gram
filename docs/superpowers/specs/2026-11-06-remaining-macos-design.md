# Завершение оформления MTW-Gram

Цель: довести оставшиеся элементы существующего recon до macOS-вида поверх tdesktop, без изменения протокола и данных.

Объём: существующие must/should из replica/features.csv; затем could — профиль пользователя, медиа-вьювер, звонки, сторис, уведомления и эффекты. skip остаётся вне объёма. no в старой матрице не является доказательством отсутствия реализации.

Подходы: отдельная копия экранов потребует дублирования логики; выбран перенос через общие стили и существующие Qt-компоненты, как в текущих патчах. Не переносить код, иконки или шрифты macOS; использовать только размеры, роли цветов и формулы.

Первый этап: общая навигационная шапка Info для профиля, настроек и общих медиа. Высота 64, заголовок 15 medium, подзаголовок 12, центрированные кнопки и поиск. Варианты обычной и плавающей шапки должны оставаться согласованными; не менять механизм сворачивания профиля.

Далее: профиль и поиск/панели; плашки и состояния сообщений; оставшиеся анимации; медиа-вьювер, звонки и сторис по исходникам. При неполном recon отмечать неизвестное, не объявлять совпадение с macOS.

Проверка: проверка вызывающих мест, Debug и воспроизводимые патчи. UI-проверку пользователь разрешил пропустить. Без сабов. Не публиковать и не пушить без команды. Существующий кандидат 0.2.0-beta сохраняется отдельно от новых изменений.
