# Recon map: Telegram (macOS 13.1, build 283357) → Qt/tdesktop на Windows

Scope: **внешний вид и поведение** macOS-клиента (окно, список чатов, чат, поле ввода, панели, профиль, настройки, модалки, меню), перенесённые на tdesktop. Сеть, протокол MTProto, хранилище и логика клиента — уже есть в tdesktop и **не клонируются**.
For: личный форк tdesktop (GPL v3), «Telegram для Windows, который выглядит как macOS-клиент».
Date: 2026-11-02

Детали чисел (цвета, отступы, кривые) — в `recon/` (tokens, layout, animations, behavior). Этот файл — карта: экраны, потоки, компоненты, модель данных, объём.

> Примечание о правилах replica-recon. Оба клиента — открытый код под GPL (`TelegramMessenger/Telegram-macOS`, `telegramdesktop/tdesktop`), поэтому чтение исходников здесь разрешено лицензией и прямо требуется CLAUDE.md. Форк остаётся GPL v3. Брендинг Telegram в форке — по правилам Telegram для неофициальных клиентов (свой api_id, не выдавать себя за официальный клиент).

## Core loop

Открыть окно → выбрать чат в левой колонке → читать ленту пузырей → написать/ответить/отреагировать в поле ввода — всё с ощущением нативного macOS-приложения (стекло, пружины, SF-метрики).

## Flows

```
F01 Открыть чат и прочитать
    S02 -> S08
    happy path clicks: 1
    edge: непрочитанные (плашка + прыжок), пин, длинная лента (кнопка «вниз» с бейджем), узкое окно (S01 single)

F02 Отправить сообщение
    S08/S11 -> ввод -> Enter
    happy path clicks: 0 (клавиатура)
    edge: авто-рост до max, вставка картинки, черновик в списке, отправка без звука (ПКМ по отправке)

F03 Ответить / изменить / переслать
    S10 -> «Ответить» -> S11 (44a) -> Enter ; S10 -> «Изменить» (44b) ; S10 -> «Переслать» -> выбор чата (модалка)
    happy path clicks: 2
    edge: свайп-ответ (D1), ↑ для правки последнего, Esc отменяет

F04 Реакция
    S10 -> эмодзи в полосе  (или двойной клик = быстрая реакция из S24/26b)
    happy path clicks: 2

F05 Вложить файл/медиа
    S14 -> выбор -> превью-модалка -> Отправить ; или drag&drop в чат
    happy path clicks: 3

F06 Стикер / эмодзи / GIF
    S13 -> клик
    happy path clicks: 2

F07 Поиск
    S07: ⌘F/клик в поиск -> ввод -> результат -> S08 с подсветкой
    edge: нет результатов (32), поиск по сообщениям, по чату (шапка)

F08 Папки
    S02 табы папок -> переключение ; S25 -> «Создать папку» (27a)
    happy path clicks: 1 / 3

F09 Профиль чата
    S08 шапка -> S15 -> табы медиа -> назад
    happy path clicks: 2

F10 Сменить тему / акцент / обои
    S16 -> S22 -> превью темы ; ночной режим по расписанию/системе (60)
    happy path clicks: 3

F11 Настройки конфиденциальности
    S16 -> S20 -> подстраница -> радио + исключения
    happy path clicks: 3

F12 Выделить и удалить/переслать много
    S10 «Выбрать» -> S12 -> клики -> действие
    happy path clicks: 3+

F13 Изменение ширины окна/колонки
    S01 перетаскивание разделителя -> 3 стадии (полная, 90pt-иконки, single)

F14 Вход (не снят)
    S32 телефон -> код -> (2FA) -> S02
```

## Inferred data model

Источник — публичная TL-схема (core.telegram.org/schema); в tdesktop всё это уже реализовано (`Data::*`), поэтому модель нужна только для понимания состояний UI.

```
User      id, first_name, last_name, username, phone, photo, status(online|recently|last_seen), premium, emoji_status, color
          evidence: S17, S20, schema user  confidence: high
Chat      id, kind(private|group|supergroup|channel|forum|secret|saved), title, photo, unread_count, unread_mentions,
          pinned, muted_until, folder_ids, draft, last_message_id
          evidence: S02, S03, S08  confidence: high
Message   id, chat_id, from_id, date, text+entities, media, reply_to, fwd_from, reactions[], views, replies, edit_date,
          out, read(state), grouped_id
          evidence: S08, S10, S11, S12  confidence: high
Reaction  emoji|custom_emoji_id, count, chosen
          evidence: S08, S10, S24  confidence: high
Folder    id, title, emoticon, include_peers, exclude_peers, flags(contacts, groups, channels, bots, muted, read, archived)
          evidence: S25 (27a)  confidence: high
Session   hash, device, platform, app, ip/region, date_active
          evidence: S27  confidence: high
Settings  theme(day|dayClassic|night|nightAccent|system), accent, wallpaper, autodownload, privacy rules, notifications
          evidence: S18–S26  confidence: high (локально, FastSettings / UserDefaults)
```

Relationships: User n–n Chat (участники), Chat 1–n Message, Message 1–n Reaction, Folder n–n Chat, User 1–n Session.

## Out of scope (cannot or should not be cloned)

- Сеть Telegram, пользователи, MTProto — используются как есть через tdesktop с собственным api_id.
- Шрифты SF Pro / SF Compact (лицензия Apple) → Inter.
- Liquid glass / NSVisualEffectView / Metal-эффекты как системные API macOS → имитация в Qt (полупрозрачность + blur, где возможно).
- Premium, Stars, Gifts, Business, TON, платежи — серверная логика Telegram; клонируем только вид экранов, которые уже есть в tdesktop.
- Контент: стикеры, эмодзи-паки, звуки уведомлений, анимированные эмодзи — принадлежат Telegram/авторам; в форке использовать то, что уже распространяется с tdesktop.
- Иконки Assets.car macOS-клиента — лицензия GPL того же проекта, но брать только как референс размеров; брендовые знаки Telegram — по правилам Telegram.
- Медиа-вьювер, звонки, сторис — живых скриншотов нет (падение / нет данных); переносить по коду, с низким приоритетом.

## Size

Экраны: 38 ключевых (из 441 контроллера; ~34 снято вживую). Потоки: 14. Сущности: 7 (все уже в tdesktop).
Hard parts: (1) пузыри с позиционными радиусами и хвостом + группировка в `HistoryView` tdesktop; (2) пружинные анимации macOS (CASpring) на `anim::`/`Ui::Animations`; (3) стекло/blur и прозрачный titlebar на Windows (DWM/Mica) в Qt; (4) 3-стадийное сужение колонки и строки 90pt; (5) настройки tdesktop устроены иначе, чем InputData-группы macOS, — придётся перекрашивать каждый Box.
Size: **L** (квартал) для полного вида; **M** для core loop (S01, S02, S08, S10, S11, S13, S16-каркас).
